# AI Operating System Installer

A provider-neutral installer for building a durable AI operating system that works across LLMs.

## Choose your starting point

### [I already use AI](START-MIGRATION.md)

Start here if you have useful chats, prompts, skills, projects, files, or intellectual property that should be evaluated and selectively carried into the new system.

### [I'm new to AI](START-FRESH.md)

Start here if you want to establish requirements, authority, storage, recovery, and cross-LLM handoffs correctly from the beginning.

Both paths converge on the shared [Installation Manual](INSTALLER.md). Do not begin with the shared manual until you have chosen a path.

## Give this repository to an AI

```text
Install this AI operating system for me. Read this repository's README and installer manifest completely. Ask me which of the two starting paths applies, then follow only that path. Verify your capabilities before acting, ask one question at a time, and do not claim completion without the required evidence.
```
