# Start Here — I'm New to AI

Use this path when the learner has little or no prior AI system to preserve.

## Start prompt

```text
Use the fresh-start path in this repository to install my AI operating system. First verify that you can read README.md, START-FRESH.md, INSTALLER-MANIFEST.json, and the final checklist in INSTALLER.md. Then ask only the first Phase 0 interview question. Do not create folders, dashboards, databases, automations, or workflows until discovery passes its exit gate.
```

## Fresh-start sequence

1. Verify the complete repository and the current AI's real capabilities.
2. Begin Phase 0 requirements discovery.
3. Learn the learner's recurring responsibilities, failures, tools, friction, authority boundaries, desired autonomy, and definition of success.
4. Define explicit non-goals so infrastructure does not become the work.
5. Build and verify the Requirements Map and Current Systems Inventory.
6. Pass the Phase 0 exit gate.
7. Continue through Phase 1 in `INSTALLER.md`.
8. Run recovery, local/remote parity, and clean-room tests.

## First Phase 0 interview question

**What recurring responsibilities depend on you and tend to fall through the cracks, create stress, cost money, or have consequences when they are missed?**

## Fresh-start exit gate

Do not begin Phase 1 until the learner has confirmed:

- recurring responsibilities and failure points;
- current tools and access limitations;
- what AI should execute autonomously;
- what requires notice, approval, or human-only action;
- sensitive and excluded locations;
- measurable 90-day success;
- the smallest foundation needed next.
